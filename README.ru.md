<a id="project-positioning"></a>
## Позиционирование проекта

qv-extras — необязательный пакет расширений для Quintet-Verify. Он предоставляет набор плагинов когнитивного усиления, которые внедряются через стандартизированные точки монтирования pre_act_hooks / post_act_hooks, предоставляемые основным фреймворком.

Все плагины по умолчанию отключены — пользователи включают их по мере необходимости через веб-консоль или в конфигурации. Ядро фреймворка не подвергается влиянию плагинов; без этого пакета вся функциональность Quintet-Verify остаётся полностью доступной.

---

<a id="design-philosophy"></a>
## Философия проектирования

- Неинвазивность — не изменяет код ядра Quintet-Verify; внедряется только через точки монтирования.  
- Включение по необходимости — все плагины по умолчанию отключены; пользователи выборочно активируют их в зависимости от требований задачи.  
- Комбинируемость — плагины независимы друг от друга и могут использоваться в любых сочетаниях.

<a id="quick-start"></a>
## Быстрый старт

<a id="installation"></a>
### Установка

Установите напрямую из исходного кода:

```bash
git clone https://github.com/Qianjinqie/Quintet-Verify-plugin.git
cd Quintet-Verify-plugin
pip install .
```

<a id="usage"></a>

### Использование

После установки плагины автоматически регистрируются в точках монтирования Quintet-Verify. Включите соответствующие флаги плагинов в веб-консоли или задайте их в конфигурации:

```python
from quintet_verify import PublicState, QuintetState

state = QuintetState(
    public=PublicState(
        task="...",
        flags={
            "plugin_a": True,   # включить плагин A
            "plugin_b": False,  # отключить плагин B
            # ...
        }
    )
)
```

<a id="theoretical-origins-and-independence-statement"></a>

## Теоретические истоки и заявление о независимости

Проектирование некоторых механизмов в qv-extras (связывание до заключения, широковещательный концентратор, метакогнитивный контроль как действие) вдохновлено J‑Space Cognition Suite V3.6 (doi:10.5281/zenodo.21971181) и опирается на его концепции «Dense Track» и когнитивных маркеров (✓/?/✗).

Однако весь код в этом репозитории реализован независимо; исходный код, шаблоны промптов и тексты протоколов из J‑Space не копировались и не переводились. Согласно определению «производного произведения» в Apache License 2.0, данный пакет плагинов — как независимый модуль, вызываемый через стандартизированные интерфейсы, — не является производным произведением или форком J‑Space.

Мы выражаем уважение и благодарность команде J‑Space за их оригинальную работу и рекомендуем читателям обращаться к ней как к полезному сравнительному материалу для понимания предпосылок проектирования этого плагина.

Полную версию заявления о теоретических истоках и независимости основного фреймворка Quintet-Verify смотрите в README основного репозитория.
